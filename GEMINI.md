## ⚡ Core Operational Principles (Non-Negotiable)

1. **Zero-Placeholder Policy (Strict 100% Completion)**:
   - **NEVER** leave `// TODO`, `// Implement here`, stub functions, or mock shortcuts in production files.
   - All code, components, controllers, and database handlers must be completely written and fully functional.
   - If a file is incomplete or missing dependencies, create or finish it completely with robust business logic.

2. **Autonomous Bug-Hunting & Self-Healing**:
   - When fixing bugs or building features, do not stop at writing code. Verify syntax, import resolution, and build health.
   - If an error occurs, proactively inspect terminal logs, run diagnostics (`debugger`, `logic-locate`), and resolve root causes.
   - When feasible, launch the preview server and verify functionality in the browser using the browser subagent.

3. **Data & Config Integrity**:
   - Never wipe existing `.env` credentials, live databases, or working configurations.
   - Create `.env.example` templates for newly introduced environment variables.

## 🎨 1. Frontend & UI Design Guidelines (Impeccable Standard)
When building or refactoring UI, dashboards, or landing pages:
- **Never Default to Generic Templates**: Avoid formulaic AI-style layouts, repetitive card grids, and plain gray surfaces.
- **Curated Typography**: Pair intentional Google Fonts (e.g., Cormorant Garamond, Inter, Plus Jakarta Sans, Outfit, Syne) matching brand mood.
- **Tinted Surfaces & Rich Dark Modes**: Never use dead black `#000000` or neutral gray `#888888`. Tint dark and light surfaces with brand undertones.
- **Craft Floor Checklist**:
  - Text Contrast: Body text >= 4.5:1, large text >= 3:1.
  - Realistic Depth: Multi-layered soft shadows with ambient blur.
  - Micro-Interactions: Fluid cubic-bezier transitions (`cubic-bezier(0.16, 1, 0.3, 1)`), hover/active states, custom scrollbars, and themed `::selection`.
  - Comprehensive UI States: Always handle empty states, loading skeletons, and clear error boundaries.
- **Available Commands**: `/impeccable init`, `/impeccable polish`, `/impeccable audit`, `/impeccable critique`, `/impeccable animate`.
